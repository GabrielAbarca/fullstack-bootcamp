## 👋 What's this?

My code and notes from working through [midudev's](https://github.com/midudev) free full-stack bootcamp, **JSCAMP**. No copy-paste speedrun here. Every project in this repo was typed out, broken at least once, and fixed by hand.

📺 **Course:** [Aprende Desarrollo Full-Stack desde Cero](https://www.youtube.com/watch?v=mXpWhmJXV0o)
📦 **Official repo:** [midudev/jscamp](https://github.com/midudev/jscamp)

## 🗺️ The Roadmap

| | Module | What gets built |
|:-:|---|---|
| 🌐 | **HTML, CSS & JS** | Semantic layouts, DOM events, `data-*` attributes, Fetch API, Web Components, first deploy |
| ⚛️ | **React** | Hooks, custom hooks, pagination, debounced filters, URL sync, React Router, lazy loading |
| 🔐 | **State & Auth** | Context API, Redux, Zustand, persistence, protected routes |
| 🟢 | **Node.js & Express** | REST API from scratch, CRUD, middlewares, CORS, MVC pattern, API deploy |
| 🧪 | **Testing** | Unit tests, schema validation with Zod, E2E tests |
| 🔷 | **TypeScript** | Types, interfaces, narrowing, typed functions |
| 🤖 | **AI & Agents** | OpenAI in the backend, streaming responses, MCPs, Agent Skills, monorepos |
| 🗄️ | **SQL** | Queries, filtering, pagination, relations, JOINs, wiring the DB into the API |
| 🧠 | **OpenCode** | Agent-driven projects with `SPEC.md` and `AGENTS.md`, custom commands |
| ⚙️ | **CI/CD** | GitHub Actions workflows, cron jobs, parallel jobs, matrices |
| 🐳 | **Docker** | Containers, Dockerfiles, volumes, production deploys |
